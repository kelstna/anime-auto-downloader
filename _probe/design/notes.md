# UI 重构记录（1.1）

## 北极星

**安静的片库**：一屏里只有封面是彩色的。
界面用中性色、发丝线和对齐说话，强调色只用来标记「当前在哪、正在做什么」。

这是一个每天打开、扫一眼就知道「哪部该更新了」的工具，不是展示页。所以：
封面是主角；数字与状态要能瞬间扫到；任何装饰都不能和封面抢注意力。

## 这一版改了什么

| 层 | 决定 | 理由 |
| --- | --- | --- |
| 表面 | 只有两级：画布 `#0a0c11` / 卡片 `#11141b`，输入与悬浮再抬一级 `#171b23`；只留发丝线 `#20252f` | 旧版面板同时有边框、阴影和嵌套底色，层级互相抵消，看不出谁在上面 |
| 字号 | 五档：11.5 / 12.5 / 14 / 15 / 26，表格 13；正文行高 1.6 | 旧版 12 / 12.5 / 13.5 / 14 / 20 混用，层级差不够，读起来发闷 |
| 控件 | 一套语法：40px 高、10px 圆角、按下 `translateY(1px)+scale(.995)`、聚焦 3px 强调色光环 | 旧版按钮/输入框/下拉各有一套高度与圆角，凑在一起像拼的 |
| 开关 | 表单里的开关和 label 同为 18px 行高（轨道行内贴左）；卡片里的开关给 28px 点击块 | 开关做成 40px 高会让同一行的 label 基线歪掉（自动化检查也会抓出来） |
| 导航 | 40px 行 + 16px 内联 SVG 图标（1.6 描边、圆头）；选中用底色不用描边 | 旧版用 `▦ ⇩ ⚙ ≡` 字符当图标，字重和大小都不受控 |
| 卡片 | 封面 3:4 占满上半部；标题最多两行；元信息纯文本用 `·` 分隔；悬浮上浮 2px + 封面推近 2% | 旧版元信息是三枚胶囊，一屏 30 张卡片时噪音很大 |
| 状态徽标 | 封面底部一条玻璃底徽标，「已订阅」= 玻璃底 + 绿点，不再用亮绿实心 | 亮绿实心在深色封面上是全场最吵的元素，而它只是「已知状态」 |
| 表格 | 表头吸顶、行高固定 44px、悬浮行底色，时间/做种/操作列不省略 | 行高靠 padding 撑会让「有按钮的行」高 4px，整张表看起来在抖 |
| 弹窗 | 18px 圆角，头部封面 88×118，页签改成下划线指示 | 旧版页签是胶囊按钮，和工具栏里的按钮语法撞车 |
| 图标 | 全部内联 SVG（关闭、外链、时钟、勾选、空状态），不用 emoji、不引图标字体 | 自包含、离线可用、粗细统一 |
| 动效 | 三处：按下反馈（90ms）、视图切换（320ms 淡入 + 上移 4px）、首次进入卡片 28ms 错峰 | 只做有反馈、有来路、有出场的那三处；重渲染不重播 |

## 配色（暖纸 + 墨）

参考用户给的一张计费台界面定了方向：**整页只有两级中性色 + 一种强调**，除封面外不出现第二块高饱和色。
蓝紫强调色全部移除（UI、占位封面、favicon 一起改），换成墨色：

- 深色（暖炭）：画布 `#121110`、侧栏 `#151412`、卡片 `#1a1917`、抬一级 `#211f1c`、线 `#2a2724`；
  正文 `#f2ede3`、辅助 `#b7b0a2`、弱信息 `#8e887b`（4.98:1）；**强调 = 骨白 `#e9e1d0`**（深色下墨色反相，主按钮是骨白底 + 墨字）。
- 浅色（暖纸）：画布 `#efebe3`、侧栏 `#f7f4ee`、卡片 `#ffffff`、抬一级 `#f6f3ec`、线 `#e3ddd1`；
  正文 `#191817`、辅助 `#524e46`、弱信息 `#6e685d`（5.5:1）；**强调 = 墨 `#1c1b19`**（主按钮墨底 + 暖白字）。
- 状态色只表达状态：ok `#8fbf72`/`#4d7c3a`、warn `#d9a53f`/`#7f540e`、bad `#e07a5f`/`#b4432b`。
- 强调色的职责被收紧成两条：**当前在哪**（导航当前项、选中态）、**现在正在发生什么**（6 小时内要更新、待下载）。
  时间戳、外链、徽章都改成中性色 —— 之前「下次更新」是蓝的，一屏 6 张卡就有 4 处蓝，信号失效。

两套主题的对比度都用脚本量过：正文/辅助/弱信息在各自底色上 ≥4.5:1，截图工具 lint 两套主题都是 0 项。

## 独立评审落地情况

按「存量界面润色评审」走了一轮（只诊断、不打分、不给整页重做），逐条处理：

**已改**

1. Token 一次性配置压成一行（面板头 + 说明 + 两个字段行 → 一行），首屏从「5 张卡 + 1 张残卡」变成两排完整封面。
2. 资源表把宽度让给标题：站点 80→68、字幕组 116→104、语言 76→62、分辨率 64→54、集数 52→44、大小 74→66、做种 64→54、发布 118→112、操作 188→150，`min-width` 1032→900，标题约多出 130px。
3. 表格里的高饱和色全部撤掉：语言胶囊改中性（靠文字区分简/繁/日），行内「下载」改描边、悬停才反相，「复制磁力」改纯文字。
4. 强调色的职责收窄：卡片「下次更新」改中性（只有 6 小时内才用强调色）、「新」徽章改中性底、「获取 Token / 更多 / 立即重试」加下划线以区分正文。
5. 主次动作摆正：「立即补下载 N 集」拿到主样式，「全部检查」降级为描边。
6. 订阅汇总把「指标」和「上次/下次运行」拆成两行，不再混排。
7. 设置页「测试连接」「查看已有文件夹」从字段网格里拿出来，变成卡片级动作。
8. 搜索详情（内部检索日志）从表格上方移到表格下方，不再占最贵的位置。
9. 「已选 0 部」静止态不显示（文字仍更新，读屏与探针读得到）。
10. 窄屏（≤980px）不再整块隐藏状态：压成一条横向小条，掉线 / 待下载几集还看得见。
11. 数字列（集数 / 大小 / 做种）右对齐；封面比例统一按 3:4 派生（网格、弹窗、侧栏缩略、最近更新）。
12. 弹窗标题 20px 正式写进字号序列（第六档，只给弹窗头用）；行内动作定一档 26px；勾选框回到 4px 网格（8px 边距、22px 容器）。

**没做 / 留到下一版**

- 字幕组信息在标题里重复出现（`[桜都字幕组]` 前缀 + 字幕组列）。删列会动到 5 个探针的列断言，这一版先把宽度让给了标题。
- 日期四种写法、容量 MB/GiB 混用属于取数层（`source_*` 与后端格式化），不在这次 UI 重构范围内。
- 弹窗「订阅设置」三列宽不齐、「将订阅」一行逐字重复字段、「下次更新」缺失时不给状态词（与「隐藏占位保证等高等」相冲），都记在待办里。
- 别名 chip 与标题完全重复时没有去重（作者/别名数据在 `bangumi.build_aliases`，去重会牵到搜索关键词逻辑）。

## 刻意保留 / 刻意不做

- **保留**：卡片墙 5~6 列的密度、番剧详情弹窗的「资源列表 / 订阅设置」结构、表格九列与列宽、
  侧栏「最近更新」与「待下载」两条信息、所有按钮文案与交互位置 —— 功能一个都没删。
- **没做**：Token 面板折叠（配置好后其实可以收起来）。它是最显眼的一处可减法，但折叠会移动
  `#token-input` 的位置，而现有 6 个自动化探针都在量这一行的对齐与高度；为了不掩盖回归，
  这一版先保持展开，留作下一版配合探针改造再做。
- **没做**：字体换成衬线标题。Windows 上中文衬线落回宋体，在大字号下发虚，风险大于收益。
